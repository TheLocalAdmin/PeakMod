# PeakMod V0.1.1 Update

## What's new in 0.1.1

- **Version bump to 0.1.1** - Plugin now reports `PeakMod V0.1.1` in-game and on the BepInEx load screen. (The previous `0.1a` label was not a valid BepInEx version string, which made the plugin fail to load - fixed.)

## What's new in 0.1 (initial release)

- **Player tab** - Infinite stamina, freeze afflictions, no-weight, no-fog, unlimited item uses, no-status toggles (eat/injury/cold/poison/curse/hot/spores/petrify/ragdoll), speed/jump/climb/rope/vine/fly modifiers, no fall damage, teleport to ping, custom teleport to coordinates.
- **Items tab** - Real-time inventory slot editing (assign any item), recharge item charges, searchable item list.
- **Spawn tab** - Spawn any item into any player's hand (works as a non-host via client-legal RPCs).
- **Lobby tab** - Player list, revive/kill selected, warp to / warp to me, spawn Scoutmaster for a player (host only).
- **World tab** - Find and interact with nearby containers/luggage, open all nearby containers, warp to luggage.
- **Stages tab** - Teleport to any mountain stage, from Beach to Peak.
- **Achievements tab** - Unlock all badges and grant ascent levels.
- **Host tab** - Master-client-only actions: kick a player, give any status to a player, remove/fill inventory slots, pass out, zombify, and move items to a player's backpack.
- **Profile tab** - Save/load all of your PLAYER tab options to `BepInEx/config/PeakModPlayerProfile.json`. Only PLAYER options are stored.

## Fixes

- Stage teleport for **Alpine** and **Peak** now also independently warps your character even if the game's internal jump logic throws, so you no longer get stuck after the map switches.
- A warning is shown in the STAGES tab when Alpine or Peak is selected (these teleports drop you in the air near the spawn - use **Fly Mode** in the PLAYER tab if you get stuck).
- **Unlimited Item Uses** now also forces `CanUsePrimary`/`CanUseSecondary` to return true, so items (e.g. balloons) stay usable even at zero uses.
- **Player Markers** toggle added (PLAYER tab) - shows every nearby player's name and distance on screen.

## Installation

1. Install **BepInEx 5.4.23.3** into your PEAK game folder (extract into the game directory, run the game once to generate `BepInEx\plugins\`).
2. Drop the **DearImGuiInjection** plugin into `BepInEx\plugins\`.
3. Copy `BepInEx\plugins\PeakMod.dll` from this repo into your game's `BepInEx\plugins\` folder **overwriting the old one**.
4. Launch the game. Press **`Z`** to open the mod menu (see README to change the key).

> If present, delete the older config at `BepInEx\config\com.thelocaladmin.peakmod.cfg` when upgrading.
