# PeakMod V0.2.0 (Beta) - Changelog

## Bug Fixes
- **No Ragdoll** now only affects your local character (was affecting all players via global patch)
- **No Fog** now only affects your local view (was a global `Fog.ApplyVisuals` block)
- **Respawn at Airport** no longer sends players thousands of blocks up — uses ground raycast detection

## New Features
- **Coordinate Overlay** (press M) — shows your position, all player positions with distance, and nearby container positions
- **Vanish Mode** (press V) — go invisible, enable fly, and show coordinate overlay
- **Team Tab** under PLAYER — apply self mods to teammates:
  - Infinite Stamina, Freeze Afflictions, Speed, Jump, Fly Mode, Climb (all 3)
  - Give status effects to teammate
  - Clear all statuses on teammate
  - Warp to / warp teammate to you
  - Revive / Kill teammate
- **Luggage ESP** (World tab) — configurable glowing boxes around nearby luggage with hex color picker
- **Badge Management** — unlock all badges and grant ascent levels (individual badge removal removed due to Steam API limitation)
- **Simplified Installation** — single zip download with BepInEx, DearImGuiInjection, and PeakMod included

## Removed
- **Time Freeze** — removed (was unstable)
- **Time Override** — removed (was unstable)
- **Time Scale** — removed entirely
- **Badge Removal** — removed due to Steam `ClearAchievements()` bug that re-grants all badges
- **Grant/Remove Badges for Other Players** — removed (Steam limitation)

## Technical Changes
- Changed from `PhotonNetwork.Instantiate` to safe respawn system
- Added `GetSafeRevivePosition()` with ground raycast
- All status mods now use local-only checks where possible
- Added config entries for Luggage ESP and Vanish Mode
- Updated DearImGuiInjection links to Penswer/DearImGuiInjection
